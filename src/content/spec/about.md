## 建站历程

本站其实诞生于一次偶然：站长在 Spaceship 上看见了打折的便宜域名，直接花 63 块 8 买下了 3 年使用权😋。

最开始是用 AI 慢慢辅助建站，后来觉得 AI 味太重了，也不知道该怎么去掉，去了也去不彻底。看看大佬们的网站，感觉大佬们做得很好，学学这个、学学那个，就改成现在这个样子了。

本站几乎不分享任何技术性东西。GitHub 上的项目，不确定能不能帮到大家；之前部分用 Python 写的，现在全转 Java 了，已经忘完了。

站点里面的游戏可以直接点，会跳转到网盘里面，大家可以直接下。网盘后缀括号里面的就是解压密码。
